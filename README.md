# Course Load Planner

Course Load Planner is a student productivity project that helps students understand which weeks of the semester may be the busiest based on assignments, exams, projects, readings, and deadlines.

## Problem

Students often see deadlines listed across multiple syllabi, Canvas pages, calendars, and notes. It can be hard to understand which weeks will be manageable and which weeks will be stressful until it is too late.

## Project goal

The goal is to build a simple tool that organizes course deadlines and shows students when their workload is likely to be highest.

## Planned features

- Add course deadlines
- Categorize events as exams, quizzes, projects, readings, or assignments
- Estimate weekly workload
- Identify busy weeks
- Show a simple workload table
- Future: visual chart of workload by week
- Future: connect with Syllabus to Calendar AI output

## Example inputs

- Course name
- Assignment title
- Due date
- Event type
- Estimated difficulty
- Estimated time needed

## Example outputs

- Weekly workload summary
- Busiest weeks of the semester
- Deadline categories
- Suggested planning notes
- Future chart or calendar view
